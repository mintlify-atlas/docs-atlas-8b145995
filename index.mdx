SCALF is a scripting language designed for developers who want predictable, zero-setup automation. Write a `.scl` script, run it with `scalf`, and get a type-checked, permission-sandboxed execution — no package manager, no runtime installs, no surprises. When you're ready, compile it into a self-contained binary for any platform.

## What makes SCALF different

<CardGroup cols={2}>
  <Card title="Secure by Default" icon="lock">
    Scripts run with no permissions unless you explicitly grant them. Network, filesystem, and environment access are all opt-in.
  </Card>
  <Card title="Zero Setup" icon="bolt">
    No `npm install`, no `pip`, no `go get`. Import stdlib modules with `use std.http` — they ship with the runtime.
  </Card>
  <Card title="Type-Checked" icon="check">
    A static type checker catches errors before your script runs. Nullable types, union types, generics, and optional chaining are all first-class.
  </Card>
  <Card title="Built-in Tooling" icon="wrench">
    Format with `scalf fmt`, lint with `scalf check`, test with `scalf test`. No configuration files required.
  </Card>
  <Card title="Standalone Binaries" icon="box">
    Compile any script into a self-contained executable for Linux, macOS, or Windows with `scalf build`.
  </Card>
  <Card title="URL Imports" icon="link">
    Import remote modules directly from URLs. SCALF caches them content-addressed and verifies integrity via a lockfile.
  </Card>
</CardGroup>

## Get started in 3 steps

<Steps>
  <Step title="Install SCALF">
    ```bash
    cargo install --path .
    ```
    Or build directly: `cargo build --release`
  </Step>
  <Step title="Write a script">
    ```python hello.scl
    name = "world"
    print("Hello, {name}!")
    ```
  </Step>
  <Step title="Run it">
    ```bash
    scalf hello.scl
    ```
  </Step>
</Steps>
