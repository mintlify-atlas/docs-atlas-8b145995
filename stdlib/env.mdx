The `std.env` module gives scripts access to the process environment. It deliberately exposes a minimal surface — a single `env.get` function — to make it easy to audit which environment variables a script reads. Because environment variables often carry API keys, tokens, and other sensitive configuration, SCALF gates this module behind an explicit permission flag.

```python
use std.env as env
```

<Warning>
  Reading environment variables requires `--allow-env`. Without it, any call to `env.get` will fail at runtime. This ensures scripts cannot silently harvest secrets from your shell environment without explicit consent.

  ```bash
  scalf --allow-env my_script.scl
  # or grant all permissions (not recommended for production)
  scalf --allow-all my_script.scl
  ```
</Warning>

## Functions

### `env.get`

Reads the value of an environment variable by name. Returns the variable's string value if it is set, or `nil` if it is not.

<ParamField path="name" type="string" required>
  The name of the environment variable to read (case-sensitive on most platforms).
</ParamField>

<ResponseField name="return" type="string | nil">
  The value of the environment variable as a string, or `nil` if the variable is not set.
</ResponseField>

```python
use std.env as env

home = env.get("HOME")
print(home)   # e.g. /home/alice
```

Use `or` to supply a default when the variable may be absent:

```python
use std.env as env

api_url = env.get("API_URL") or "https://api.example.com"
token   = env.get("API_TOKEN") or ""

if token == "" {
  print("⚠️  API_TOKEN is not set")
}
```

## Examples

### Reading common shell variables

```python
use std.env as env

home  = env.get("HOME")
shell = env.get("SHELL")
path  = env.get("PATH")

print("Home:  {home}")
print("Shell: {shell}")
print("PATH:  {path}")
```

### Loading configuration from the environment

A common pattern for twelve-factor style scripts is to read all configuration up front and fail early if required variables are missing:

```python
#!/usr/bin/env scalf --allow-env --allow-net=api.example.com

use std.env as env
use std.http as http

db_url    = env.get("DATABASE_URL") or ""
api_token = env.get("API_TOKEN") or ""

if db_url == "" {
  print("❌ DATABASE_URL is required")
  exit(1)
}

if api_token == "" {
  print("❌ API_TOKEN is required")
  exit(1)
}

response = http.get(
  "https://api.example.com/sync",
  { "Authorization": "Bearer {api_token}" }
)
print("Sync status: {response.status}")
```

<Note>
  `env.get` always returns a string (or `nil`). If you need a numeric value — for example, a port number — convert it explicitly after reading:

  ```python
  port_str = env.get("PORT") or "8080"
  port = int(port_str)
  ```
</Note>
